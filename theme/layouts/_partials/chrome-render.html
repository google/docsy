{{/* Returns whether the partial's REGION should render on the current PAGE. With the `shared` chrome build mode (td.chrome) enabled, each repeated, auto-generated region is kept on just enough pages for a link checker to reach every link once; the dropped instances are restored in the browser (see _partials/navbar.html, footer.html, sidebar.html and assets/js/chrome-nav.js) so the shared build aims to stay functionally equivalent to a full one (known gaps: tests/fixture-site/README.md § Open items). The regions kept are: navbar, footer config-defined chrome -> each locale's root page (HTML render) sidebar computed left-nav -> each locale's docs landing page The root page is the page publishing the locale's root URL (td/root-page.html): the home page, or the docs landing on a doc-rooted site, whose home never renders. In `full` mode (the default), every region renders. See the chrome build modes guide for what this is and how to enable it: docsy.dev/content/en/docs/deployment/chrome.md ctx: dict "page" PAGE "region" REGION */ -}} {{ $p := .page -}} {{ $render := true -}} {{ if eq ($p.Param "td.chrome") "shared" -}} {{ if eq .region "sidebar" -}} {{ $root := cond (and (ne $p.Params.toc_root true) (eq $p.Site.Home.Type "docs")) $p.Site.Home $p.FirstSection -}} {{ $render = and $root (eq $p.RelPermalink $root.RelPermalink) -}} {{ else -}} {{/* The root page's HTML render only: the HTML format is the current one when it is among the page's formats but not its alternatives, so the page's print render gets a placeholder like any other page. */ -}} {{ $html := and ($p.OutputFormats.Get "html") (not ($p.AlternativeOutputFormats.Get "html")) -}} {{ $render = and $html ($p.Eq (partialCached "td/root-page.html" $p.Site $p.Site.Home.Permalink)) -}} {{ end -}} {{ end -}} {{ return $render -}}
